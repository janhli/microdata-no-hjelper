## Test 8.1: Manglende verdier i regresjoner
Hva testes: om `regress` utelater enheter som mangler en av variablene (listevis utelatelse).

**Forventet hvis antakelsen stemmer:** Antall observasjoner i regresjonen er omtrent lik cellen
«mangler_utd = 0, mangler_lonn = 0» i tabellen over (±5 for støy). Er N lik hele populasjonen, er
manglende verdier fylt inn eller satt til 0, og det må inn i fallgruver.md.
endblock
regress lonn mann utd1

textblock
## Test 8.2: Sammenligning med manglende verdi
Hva testes: hva `utd1 > 5`, `utd1 != 2` og `replace ... if utd1 > 5` gir når `utd1` mangler.

**Forventet hvis antakelsen stemmer:** Uavklart. I Stata regnes manglende som uendelig stor, så
`utd1 > 5` blir 1 og `utd1 != 2` blir 1. Se på raden der mangler_utd = 1 i hver tabell:
- Står de under 1: manglende teller som sant (som Stata). Dummyer fra sammenligninger blir feil uten
  `if sysmiss(...) == 0`.
- Står de under 0: manglende teller som usant.
- Står de som missing: sammenligningen gir missing, og enhetene faller ut av regresjoner.
endblock
generate h_gt = utd1 > 5
generate h_ne = utd1 != 2
generate h_if = 0
replace h_if = 1 if utd1 > 5
tabulate mangler_utd h_gt, missing
tabulate mangler_utd h_ne, missing
tabulate mangler_utd h_if, missing

## Test 8.3: Regresjon mot winsorisert gjennomsnitt
Hva testes: om regresjoner bruker data uten winsorisering (tiltak 2), mens tabeller winsoriseres.

**Forventet hvis antakelsen stemmer:** Konstantleddet (kvinner) og konstantledd + koeffisienten for mann
(menn) er litt **høyere** enn gjennomsnittene i tabellen, fordi de høyeste lønningene ikke er kuttet.
Er de like, winsoriseres også regresjonen.
endblock
tabulate mann if mangler_lonn == 0, summarize(lonn) mean
regress lonn mann if mangler_lonn == 0

textblock
## Test 8.7: Marginaleffekt for en 0/1-variabel i logit
Hva testes: om `mfx(dydx)` for dummyen `mann` er en diskret endring (fra 0 til 1) eller en derivert.

**Forventet:** Uavklart. Sammenlign dy/dx for `mann` i første utskrift med forskjellen mellom de to
predikerte verdiene i andre utskrift (`margins(mann)`). Er de nesten like, er det trolig diskret
endring. Merk: `margins()` måles ved gjennomsnittet av alder, `mfx` er gjennomsnitt over alle, så
de blir ikke helt like.
endblock
generate hoy = 0 if mangler_lonn == 0
replace hoy = 1 if lonn > 600000 & mangler_lonn == 0
tabulate hoy, missing
logit hoy mann alder, mfx(dydx)
logit hoy mann alder, margins(mann)

## Test 8.5: `regress-panel-diff` mot pooled panelregresjon med interaksjon
Hva testes: om variabel 3 i `regress-panel-diff` er etter-perioden for alle enheter, og om resultatet er
det samme som `regress-panel ... gruppe##etter, pooled` (manualen sier det). Gruppe = kvinner,
etter = 2020 og 2021. Dette er bare en test av syntaksen, ikke en meningsfull effekt.

**Forventet hvis antakelsen stemmer:** ATET i første utskrift er lik koeffisienten for
interaksjonsleddet `gruppe#etter` i andre utskrift.
endblock
