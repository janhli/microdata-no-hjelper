# Kursmateriale

I denne samlingen finner man skript som er blitt benyttet i innføringskurs og temakurs i microdata.no. I temakurs-skriptene finner man mye nyttig dersom man behersker analyseverktøyet godt, og trenger tips til løsning av ulike problemer.
