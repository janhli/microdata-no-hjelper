# Systemendringer som kan påvirke ytelse

Import, bearbeiding og analyse i microdata.no handler ofte om store datamengder, og er ytelseskrevende.

For at skript og analyser skal gå så raskt som mulig, prøver vi så godt vi kan å ta vare på resultatene av allerede eksekverte kommandoer i forskjellige hurtiglagre (cache) i tjenesten.

Noen ganger blir imidlertid informasjonen i hurtlageret utdatert og må gjenskapes. Dette kan skyldes at det er en stund siden du sist brukte microdata.no, eller det kan skyldes systemendringer som krever at hurtiglagrene nullstilles.

Når dette skjer, kan du oppleve at skript og analyser går saktere i en periode, mens hurtiglagrene bygges opp igjen mens du jobber.

Denne formen for ytelsesreduksjon er altså midlertidig, og etter hvert vil ytelsen oppleves raskere igjen.

Vi dokumenterer nedenfor med dato og forklaring systemendringer som krever at hurtiglagrene nullstilles og som derfor kan påvirke ytelsen midlertidig.
