# Brukermanual for analyseverktøyet i microdata.no

Brukermanualen gir deg full innføring i hvordan analyseverktøyet i microdata.no fungerer, alt fra brukergrensesnittet, hvordan data struktureres, hvordan kommandoer fungerer, og hva systemet kan brukes til. Du finner også oversikt over alle tilgjengelige kommandoer og funksjoner, samt konfidensialitetstiltak som har til funksjon å forhindre innsyn i personopplysninger.

Søkefeltet  øverst til høyre kan brukes til å søke etter emner og kommandoer i brukermanualen.

### Nyttige lenker

- Brukermanual
- Kommandoer og funksjoner
- Analyseeksempler
- En enkel innføring i microdata.no
- Konfidensialitet
- Årsaker til avvik mellom tall fra microdata.no og SSBs statistikk
- Systemendringer som kan påvirke resultater
- Systemendringer som kan påvirke ytelsen
- Ofte stilte spørsmål
