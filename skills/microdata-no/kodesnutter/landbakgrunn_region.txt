// Landbakgrunn gruppert i verdensregioner
// Status:    testet i større skript (no.ssb.fdb:57, 2026-11)
// Variabler: BEFOLKNING_LANDBAK3GEN (fast, SSBs landkoder)
//            https://microdata.no/discovery/variable/no.ssb.fdb/58/BEFOLKNING_LANDBAK3GEN
// Lager:     landbak – 0 Norge, 1 EU/EØS, 2 Europa utenom EU/EØS, 3 Afrika, 4 Asia med Tyrkia,
//            5 Nord-Amerika, 6 Sør- og Mellom-Amerika, 7 Oseania, 8 Statsløse, 9 Uoppgitt
// Fallgruver:
//   - Rekkefølgen i recode betyr noe. Europa utenom EU/EØS må komme før det brede intervallet
//     for Europa, og Tyrkia (143) må legges til Asia.
//   - Grupperingen følger EU/EØS slik den er i dag (Storbritannia er utenfor).
//   - Tabeller for enkeltland på små populasjoner stoppes av avsløringskontrollen.
// =====================================================================

require no.ssb.fdb:57 as fdb

create-dataset personer
import fdb/BEFOLKNING_KOMMNR_FORMELL 2025-01-01 as kommune
import fdb/BEFOLKNING_LANDBAK3GEN as landbak

destring landbak
recode landbak (111 120 138 139 140 148 155 156 159/164 = 2) (101/141 144/158 = 1) (203/393 = 3) (143 404/578 = 4) (612 684 = 5) (601/775 = 6) (802/840 = 7) (980 = 8) (990 = 9)
define-labels vregion 0 'Norge' 1 'EU/EØS' 2 'Europa utenom EU/EØS' 3 'Afrika' 4 'Asia med Tyrkia' 5 'Nord-Amerika' 6 'Sør- og Mellom-Amerika' 7 'Oseania' 8 'Statsløse' 9 'Uoppgitt'
assign-labels landbak vregion

textblock
## Bosatte etter landbakgrunn (verdensregion), 1.1.2025
endblock
tabulate landbak, missing
