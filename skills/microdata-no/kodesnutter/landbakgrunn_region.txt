//            1.1.2025. EU/EØS 710 473, Europa utenom 267 378
// Variabler: BEFOLKNING_LANDBAK3GEN (fast, SSBs landkoder)
//            https://microdata.no/discovery/variable/no.ssb.fdb/59/BEFOLKNING_LANDBAK3GEN
// Lager:     landbak – 0 Norge, 1 EU/EØS, 2 Europa utenom EU/EØS, 3 Afrika, 4 Asia med Tyrkia,
//            5 Nord-Amerika, 6 Sør- og Mellom-Amerika, 7 Oseania. Statsløse og uoppgitt står med
//            originalkoden (980, 989, 990) og navn
// Fallgruver:
//   - Verdensdelene følger SSB Klass 545 (verdensinndeling): Kypros (500) er Europa, Tyrkia (143)
//     er Asia, og Bermuda (606) og Saint-Pierre-et-Miquelon (676) er Nord-Amerika.
//   - EU/EØS er de 27 EU-landene og Island og Liechtenstein, slik det er i dag. Storbritannia,
//     Sveits (EFTA, ikke EØS), Grønland, Færøyene, Gibraltar og småstatene (Andorra, Monaco, San Marino,
//     Vatikanstaten) er Europa utenom EU/EØS. Utgåtte land: Tsjekkoslovakia (142) og DDR (151) er EU,
//     Sovjetunionen (135) og Serbia og Montenegro (125) er utenom.
//   - Rekkefølgen i recode betyr noe: en verdi som er omkodet, påvirkes ikke av senere regler i samme
//     kommando. Derfor står EU/EØS-listen og Tyrkia før intervallet 102/199, og Kypros før 404/599.
//   - Uspesifiserte koder («Resten av Afrika», «Asia uspesifisert» osv., x94–x99) er med i
//     verdensdelen sin. 194–199 er Europa utenom EU/EØS.
//   - Statsløs (980), uoppgitt utenlandsk statsborgerskap (989) og uoppgitt (990) har til sammen
//     under 10 bosatte. En recode-regel som treffer så få stoppes av avsløringskontrollen, også når
//     de tre slås sammen (testet versjon 59, november 2026). De omkodes derfor ikke, men får navn.
//   - Tabeller for enkeltland på små populasjoner stoppes av avsløringskontrollen.
// =====================================================================
